# Приложение Д. Руководство преподавателя

Как собрать курс на Платформе, провести контроль и выставить итоговые оценки.

---

## 1. С чего начать

После входа откройте раздел **«Мои курсы»**. Здесь перечислены дисциплины,
на которые вы назначены, сгруппированные по академическим периодам.

Если список пуст — назначение на дисциплину выполняет офис регистратора.
Наличие роли «Преподаватель» само по себе доступа к курсам не даёт: нужно
назначение на конкретную дисциплину в конкретном периоде.

На карточке каждого курса виден индикатор распределения часов. Он показывает,
сколько академических часов вы уже распределили по элементам содержания
и сколько требуется по объёму дисциплины в кредитах.

---

## 2. Главное правило: часы должны сойтись

**Курс нельзя опубликовать, пока сумма плановых часов всех элементов
не совпадёт с объёмом дисциплины.**

```
Сумма плановых академических часов = кредиты × 30
```

Для дисциплины объёмом 3 кредита это 90 академических часов, для 5 кредитов — 150.

Индикатор распределения виден постоянно — в конструкторе он закреплён справа.
Пока часы не сошлись, кнопка «Опубликовать» неактивна, а под ней указано,
на сколько часов расхождение.

Это не придирка системы: объём дисциплины в кредитах — предмет проверки
контролирующими органами, и курс с неверным объёмом создаёт проблему вузу,
а не только вам.

---

## 3. Копирование курса прошлого периода

**Если вы уже вели эту дисциплину — начните отсюда, а не с чистого листа.**

На вкладке **«Обзор»** есть блок «Копировать из курса прошлого периода».
Выберите период и нажмите «Скопировать содержание».

Копируются: модули, все элементы содержания, силлабус, банк вопросов,
настройки тестов и заданий.

Не копируются: регистрации студентов, оценки, данные об активности —
они относятся к прошлому потоку.

После копирования пройдите по содержанию и обновите то, что изменилось:
сроки сдачи заданий сдвинутся на новый период автоматически не будут,
их нужно поправить вручную.

---

## 4. Сборка курса

Откройте вкладку **«Конструктор содержания»**.

### 4.1. Модули

Модуль — это раздел курса, обычно соответствующий учебной неделе или теме.
Укажите название и, если модули соответствуют неделям, номер недели.

Порядок модулей меняется стрелками слева от заголовка.

### 4.2. Элементы содержания

Внутри модуля добавляются элементы. Доступно шесть типов:

| Тип | Для чего | Как засчитывается завершение |
|---|---|---|
| **Лекция (текст)** | Текст во встроенном редакторе | По времени работы с материалом |
| **Файл** | PDF, презентация, документ | По времени работы с материалом |
| **Видео по ссылке** | YouTube или Vimeo | По фактически просмотренной доле ролика |
| **Тест** | Автоматически проверяемый контроль | При наборе проходного балла |
| **Задание** | Работа с загрузкой файла | При сдаче работы |
| **Внешний ресурс** | Ссылка на сторонний материал | По времени работы |

Для каждого элемента **обязательно** указываются два параметра:

- **Плановая трудоёмкость** — сколько академических часов отведено на элемент.
  Именно из этих значений складывается общий объём курса.
- **Вид учебной работы** — лекция, практическое занятие, лабораторное занятие,
  СРОП или СРО.

### 4.3. Как распределять часы

Ориентир для дисциплины в 3 кредита (90 часов):

| Вид работы | Часов | Доля |
|---|---|---|
| Лекции | 15 | 17 % |
| Практические и лабораторные занятия | 20 | 22 % |
| СРОП | 10 | 11 % |
| СРО | 45 | 50 % |

Конкретное соотношение задаётся рабочим учебным планом. Если вуз установил
обязательный норматив, система будет его проверять — соответствующая настройка
включается администратором.

### 4.4. Текст лекции

Редактор поддерживает заголовки, списки, цитаты, таблицы, изображения
и вставки кода. Формулы вставляйте как код TeX — они отображаются
моноширинным шрифтом; полноценный рендеринг формул планируется на этапе 2.

Пишите строками разумной длины: студенту текст показывается в колонке
шириной 65–75 символов — так читается лучше всего.

### 4.5. Файлы

Нажмите на элемент, откройте блок «Файлы» и выберите файлы.
Допустимые форматы: PDF, DOCX, PPTX, XLSX, изображения, текст.
Максимальный размер — 100 МБ.

Файл загружается напрямую в хранилище, минуя сервер приложения, поэтому
загрузка больших файлов проходит быстро.

PDF студент читает во встроенном просмотрщике. Если для курса включено
ограничение скачивания, сохранить файл на устройство он не сможет.

### 4.6. Видео

Вставьте ссылку на YouTube или Vimeo — система сама определит идентификатор ролика.

**Важно: размещайте видео только на корпоративном аккаунте вуза.**
Ролики на личном аккаунте преподавателя вуз теряет при его увольнении.
Это требование регламента работы с Платформой, а не рекомендация.

Просмотр засчитывается по фактически просмотренной доле ролика.
Открыть страницу и уйти — не поможет: система считает именно просмотр.

---

## 5. Банк вопросов

Вкладка **«Банк вопросов»**. Вопросы хранятся в банке курса и потом
подбираются в тесты — один и тот же вопрос может использоваться
в нескольких тестах.

### Типы вопросов

| Тип | Особенности |
|---|---|
| Один вариант из нескольких | Ровно один верный ответ |
| Несколько вариантов из нескольких | Частичный балл за частично верный ответ |
| Установление соответствия | Пары «левое — правое», частичный балл |
| Установление последовательности | Элементы вводятся в правильном порядке |
| Ввод короткого ответа | Несколько допустимых формулировок, регистр не учитывается |
| Верно / неверно | Частный случай выбора одного варианта |

### Импорт из XLSX

Скачайте шаблон кнопкой «Шаблон XLSX» — на втором листе есть инструкция
по каждой колонке. Заполните и загрузите кнопкой «Импорт вопросов из XLSX».

Если в файле есть ошибки, система покажет номер строки и причину, а корректные
вопросы всё равно импортирует. Это быстрее, чем вводить 50 вопросов вручную.

### Пометки для отбора

Указывайте **тему** и **сложность** — они позволяют потом настроить
случайную выборку: «10 вопросов из темы „Оценивание“ средней сложности».

---

## 6. Настройка теста

Откройте элемент типа «Тест» в конструкторе.

| Параметр | На что влияет |
|---|---|
| Ограничение времени | Отсчёт идёт непрерывно, в том числе при обрыве связи |
| Число попыток | Сколько раз студент может пройти тест |
| Итог по попыткам | Лучшая, последняя, первая или средняя |
| Проходной балл | Порог засчитывания элемента как завершённого |
| Случайный порядок вопросов и вариантов | Затрудняет списывание |
| Показывать результат сразу | Если выключить — студент увидит балл после проверки |
| Случайная выборка из банка | У каждого студента свой набор вопросов |

Ниже отметьте вопросы, которые войдут в тест, и при необходимости
измените балл за каждый.

**О сохранении при обрыве связи.** Ответы сохраняются сразу после выбора,
а порядок вопросов закрепляется за попыткой. Если у студента пропал интернет,
он вернётся к тому же тесту с теми же ответами. Отсчёт времени при этом
не останавливается — предупредите об этом студентов.

---

## 7. Задания с файлами

Откройте элемент типа «Задание».

| Параметр | Комментарий |
|---|---|
| Формулировка | Что именно требуется сделать |
| Срок сдачи | Дата и время |
| Принимать после срока | Если выключить — приём закрывается жёстко |
| Снижение за день просрочки | По умолчанию 10 % |
| Максимальное снижение | По умолчанию 50 % |
| Максимальный балл | По умолчанию 100 |
| Допустимые форматы | Через запятую: `pdf, docx` |
| Число файлов и размер | По умолчанию 3 файла до 20 МБ |

Штраф за просрочку применяется автоматически: вы ставите балл за содержание
работы, а система пересчитывает его с учётом числа дней опоздания.

---

## 8. Проверка работ

Вкладка **«Проверка работ»**. По умолчанию открыт фильтр «Непроверенные».

По каждой работе видно: кто сдал, когда, была ли просрочка и сколько дней.
Файлы открываются по ссылке — они защищены, ссылка действует 15 минут.

Поставьте балл, напишите комментарий и нажмите «Выставить балл».
Балл автоматически попадёт в журнал.

Если работа требует доработки — нажмите «Вернуть на доработку».
Студент получит уведомление и сможет загрузить новую версию.

---

## 9. Журнал

Вкладка **«Журнал»** — сводная таблица «студенты × оценочные мероприятия».

### Оценочные мероприятия

Сначала опишите, из чего складывается оценка. Для каждого мероприятия
указываются период контроля (РК1, РК2, экзамен), максимальный балл и вес
внутри периода.

Пример для РК1: тест — вес 40 %, задание — вес 60 %.

Мероприятия, привязанные к тесту или заданию, заполняются автоматически —
править их вручную не нужно.

### Ввод баллов

Щёлкните по ячейке и введите балл. Правые колонки — РК1, РК2, рейтинг
допуска, экзамен, итоговый балл, буквенная оценка — пересчитываются сами.

### Как считается итог

```
Рейтинг допуска = (РК1 + РК2) / 2
Итоговый балл   = Рейтинг допуска × 0,6 + Экзамен × 0,4
```

Допуск к экзамену — при рейтинге не ниже 50 баллов. Не допущенный студент
получает F независимо от результата экзамена.

FX (25–49 баллов) даёт право на повторную сдачу экзамена без повторного
изучения дисциплины. F (0–24) — не даёт.

Коэффициенты задаются академической политикой вуза и могут отличаться —
актуальные значения показаны над журналом.

### Ведомости

Кнопками РК1, РК2 и «Экзамен» ведомость выгружается в XLSX.

**После закрытия ведомости изменить оценку нельзя.** Закрывает ведомость
офис регистратора. Если после закрытия обнаружена ошибка — обратитесь
в офис регистратора: корректировка возможна только с указанием основания
и фиксируется в журнале аудита.

## 10. Аналитика

Вкладка **«Аналитика»** показывает:

- долю студентов, завершивших курс, и средний прогресс;
- среднее время освоения;
- распределение баллов по результатам тестов;
- **статистику сложности вопросов** — вопросы отсортированы от самых сложных;
- **список студентов без активности** — с адресами для связи.

Два показателя стоит смотреть регулярно. Вопрос, на который верно отвечают
менее 40 % — повод проверить формулировку: часто дело не в сложности темы,
а в неоднозначной постановке. Студенты без активности через две недели после
начала периода — повод написать письмо, пока отставание поправимо.

---

## 11. Публикация курса

Порядок:

1. Проверьте, что часы сошлись — индикатор на вкладке «Обзор» должен быть зелёным.
2. Заполните силлабус.
3. Нажмите **«Отправить методисту»** — курс уйдёт на согласование.
4. После согласования нажмите **«Опубликовать»**.

Если методист вернул курс на доработку, причина будет показана вверху
страницы обзора.

Отдельно от публикации есть флажок **«Показывать в публичном каталоге»**.
Он управляет только видимостью карточки курса неавторизованным посетителям —
учебное содержимое им недоступно в любом случае.

---

## 12. Объявления

На вкладке «Обзор» есть блок объявлений. Опубликованное объявление
появится на странице курса у всех зачисленных студентов, и каждый
получит уведомление.

---

## Частые вопросы

**Не сходятся часы, а добавлять больше нечего.**
Проверьте СРО: самостоятельная работа обучающегося обычно составляет
около половины объёма дисциплины, и её часто недооценивают при планировании.

**Студент жалуется, что время не засчитывается.**
Время засчитывается только при активном взаимодействии со страницей.
Открытая вкладка без действий не считается. При бездействии дольше 5 минут
сессия закрывается. На один элемент засчитывается не более 150 % плановых часов.

**Хочу поменять балл после закрытия ведомости.**
Обратитесь в офис регистратора. Корректировка требует указания основания
и фиксируется в журнале аудита с прежним и новым значением.

**Тест проверился неверно.**
Откройте вопрос в банке и проверьте отмеченные верные варианты. Для вопросов
с коротким ответом убедитесь, что перечислены все допустимые формулировки —
регистр и лишние пробелы система игнорирует, но синонимы нужно указывать явно.
